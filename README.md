Rufai-VR Headsets Landing Page
A responsive landing page for a fictional VR headset product. This was my first web development project, built to master the fundamentals of HTML, CSS, and responsive design using media queries.

🔗 Live Demo: https://rufai-web-project-html-css-starter.web.app/

✨ Features
Semantic HTML5 Structure: Built with semantic tags (<header>, <nav>, <section>, <footer>) for accessibility and clean code.

Responsive Design: Uses CSS media queries to adapt the layout across desktop, tablet, and mobile screens.

Modern CSS Styling: Custom styling with Flexbox for layout, custom properties (CSS variables), and hover effects.

Clean Typography: Carefully chosen font stack and spacing for readability.

🛠️ Tech Stack
HTML5: Semantic markup and structure

CSS3: Flexbox, media queries, and custom properties

Deployment: Firebase Hosting

🚀 What I Learned
This project marked the beginning of my software development journey. Through it, I learned:

How to structure a webpage with semantic HTML

The box model, specificity, and the cascade in CSS

How to use Flexbox to create flexible, responsive layouts

How to write media queries to adapt designs for mobile devices

The importance of clean, readable code from the very start
